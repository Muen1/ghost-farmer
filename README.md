# Ghost Farmer

An offline chatbot that channels the spirit of an ancestor farmer. Ask about planting, soil, pests and harvest. He answers using your own family's farming memories from `stories.txt`.

Built for the Hacktoberfest Open-Source AI Challenge (Ghost in the Machine).

## Run it
1. Install [Ollama](https://ollama.com) and run `ollama pull gemma3:1b`
2. `pip install ollama`
3. Edit `stories.txt` with your own family memories
4. `python ghost_farmer.py`

## Why open-source AI
Runs fully offline on a laptop, free, private, and you can swap the model by changing one line.
