# Ghost Farmer

This is an offline chatbot that channels the spirit of an ancestor farmer. You can ask about planting, soil, pests and harvest. He answers using my family's farming memories from `stories.txt`.

I built for the Hacktoberfest Open-Source AI Challenge (Ghost in the Machine).

## How to run it
1. Install [Ollama](https://ollama.com) and run `ollama pull gemma3:1b`
2. `pip install ollama`
3. Edit `stories.txt` with your own family memories
4. `python ghost_farmer.py`
